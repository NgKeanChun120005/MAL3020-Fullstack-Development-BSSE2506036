# Takeaway Ordering System

MAL3020 Full-Stack Development — Assessment 2

Real-time takeaway ordering system with:
- **Frontend**: Angular
- **Backend**: Node.js + Express + Socket.IO
- **Database**: MongoDB

## Roles
- **Customer** — browse menu, place orders, track status live
- **Kitchen Staff** — view incoming orders, advance status
- **Admin** — manage menu items, view all orders
